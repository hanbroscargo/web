# Hanbros Cargo Web Sitesi

## Proje Özeti
Bu proje, Hanbros Cargo için hazırlanmış statik web sitesi çatısıdır. WebYapar altyapısı kullanılarak yönetilmektedir.

## Yapı
- `page/`: Sayfa içerikleri (HTML).
- `img/`: Görsel dosyalar.
- `module/`: Tekrar kullanılabilir bileşenler.
- `*.json`: Site ayarları, içerik verileri ve modül tanımları.

## Kullanım
Sayfalar doğrudan `page/` dizini altında tutulur. İçerik güncellemeleri için ilgili JSON dosyaları ve HTML şablonları düzenlenmelidir.
